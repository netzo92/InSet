# InSet Product Vision

## Mission

Enable teams of all sizes to build safe, high-quality AI assistants through transparent workflows, rigorous evaluation, and rich collaboration tools.

## Target Users

1. **AI product teams** who need to iterate quickly on agent behavior while maintaining quality.
2. **Safety & policy reviewers** ensuring responsible AI output through red-teaming and audits.
3. **Operations teams** supporting live agents with monitoring, analytics, and lifecycle management.
4. **Researchers & community builders** experimenting with new evaluation techniques and model integrations.

## Core Use Cases

- **Authoring & configuration** – Manage prompts, tools, memory, routing logic, and release versions.
- **Evaluation & testing** – Define automated regression suites, run batch evaluations, and collect human ratings.
- **Governance & compliance** – Track approvals, enforce policies, and monitor for risky behaviors.
- **Analytics & observability** – Understand performance trends, user satisfaction, and model costs.
- **Live collaboration & interviews** – Co-create sessions with stakeholders and run moderated LiveKit conversations for hiring or trust & safety reviews.

## Value Propositions

- Open-source transparency with enterprise-grade features.
- Pluggable adapters for any LLM or tool provider.
- Collaborative workspace with role-based permissions and review flows.
- Extensible evaluation engine supporting custom metrics and judge models.
- LiveKit-powered interview mode for moderated real-time sessions with shared annotations.

## Competitive Differentiators

- Vendor-neutral architecture suitable for self-hosting or hybrid deployments.
- Comprehensive observability stack with built-in dashboards and alerting.
- Strong focus on safety workflows (red teaming, incident response, audit trails).
- Active community contributing adapters, evaluation recipes, and UI extensions.

## Success Metrics

- Time-to-release for new agent versions.
- Reduction in safety incidents post-deployment.
- Coverage of automated regression tests vs. critical flows.
- Community growth (contributors, adapters, evaluation recipes).

## Release Milestones

1. **MVP (v0.1)** – Core project scaffolding, agent configuration CRUD, manual evaluation runs.
2. **Beta (v0.5)** – Automated evaluation engine, analytics dashboards, initial governance workflows, and an initial LiveKit experience for moderated sessions.
3. **Launch (v1.0)** – End-to-end collaboration features, integrations marketplace, deployment tooling.
4. **Enterprise (v2.0+)** – Advanced policy controls, enterprise SSO, fine-grained audit & compliance tooling.

## Community & Governance

- Use an RFC process for significant architectural decisions.
- Publish design docs and evaluations openly for transparency.
- Hold monthly community calls to gather feedback and align roadmap.
- Adopt a contributor ladder recognizing sustained involvement.
